# 🛍️ E-commerce Completo

Un e-commerce moderno costruito con React.js, Node.js, Express e MongoDB.

## 🚀 Funzionalità Principali

- ✅ Sistema di autenticazione utente
- ✅ Carrello della spesa e wishlist
- ✅ Pagamenti con Stripe
- ✅ Recensioni e valutazioni prodotti
- ✅ Dashboard amministratore
- ✅ Ricerca avanzata e filtri
- ✅ Gestione ordini e tracking
- ✅ Responsive design

## 🛠 Tecnologie Utilizzate

### Frontend
- React.js 18
- React Router DOM
- Context API
- Styled Components
- Axios

### Backend
- Node.js
- Express.js
- MongoDB con Mongoose
- JWT Authentication
- Multer per upload file
- Nodemailer
